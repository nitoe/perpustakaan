# CHANGELOG

## 0.7.0 — Pengaturan & bantuan input buku
- Halaman Pengaturan: profil (nama/gelar), ganti sandi, aturan pinjam (admin), referensi DDC, bantuan input.
- Form buku: Cari ISBN / Cari judul via Open Library; pilih hasil untuk mengisi judul, pengarang, penerbit, tahun, ISBN, sinopsis.
- Field klasifikasi: datalist ringkasan DDC + notasi Islam 2X0–2X9 (kebiasaan perpustakaan sekolah/madrasah Indonesia).
- CSP Report-Only: izinkan connect ke openlibrary.org dan gambar covers.openlibrary.org.

## 0.6.0 — Anggota
- Modul Anggota: daftar, tambah, ubah, nonaktifkan/aktifkan; hapus khusus admin.
- Jenis: guru, karyawan, kelas (pojok baca). ID dokumen dipakai di Sirkulasi (tab Anggota).
- Siswa tidak didaftarkan di sini — tetap lewat NISN dari Penilaian.

## 0.5.0 — Koleksi digital

- Menu Digital diaktifkan untuk semua peran staf.
